# Changelog

All notable changes to Live Call-and-Response will be documented in this file.

This project follows a simple public changelog format inspired by Keep a Changelog. Dates use UTC.

## Unreleased

### Added

- Basic GitHub Actions CI for Python syntax checks.
- CI badge in the README.
- GitHub topics for MIDI, generative music, live performance, and realtime audio.
- Contributing guide, support guide, roadmap, security policy, and structured issue forms.

### Changed

- Public-facing documentation and debug labels now use English.
- Repository description now emphasizes realtime MIDI call-and-response, symbolic music improvisation, transformer backends, and evaluation tools.

## 0.1.0

### Added

- Realtime MIDI call-and-response engine.
- MIDI endpoint detector.
- Local FastAPI/WebSocket web studio.
- Offline A/B listening sample generator.
- Objective melody metric tools.
- AMT backend integration notes and third-party attribution.
